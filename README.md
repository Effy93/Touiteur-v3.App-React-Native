## Contexte
Projet réalisé en 2019 dans le cadre de la formation **DWWM**.  
Objectif : découvrir le développement mobile avec **React Native** et **Expo**, en créant une mini application de type réseau social pour poster des messages (les "touits").  

Chaque étudiant avait sa propre version de l’application. Ce projet représente ma première expérience mobile et me permet de montrer mon parcours d’apprentissage.

## Ce que j’ai appris
- Structurer une application mobile avec **React Native**  
- Comprendre le fonctionnement d’une **API** et de la communication frontend/backend  
- Installer et utiliser **Expo** pour lancer une app sur émulateur ou smartphone  
- Gérer des dépendances avec **npm**  
- Notions basiques de **UI/UX mobile** et mise en page  

## Ce que je referais différemment aujourd’hui
- Améliorer la gestion des dépendances et les versions des packages  
- Moderniser l’interface et suivre les normes UI/UX actuelles  
- Documenter le projet de façon plus claire et structurée  

## Installation / utilisation (historique)
> ⚠️ Projet réalisé en 2019 : certaines étapes peuvent ne plus fonctionner sur les versions actuelles de React Native / Expo.

### Pré-requis
    - Sur mac : émulateur d'iphone => installez **Xcode** depuis l'app-store.
    - Sur smartphone : appli Expo => installez **Expo** depuis le Store.
    - Npm

## 1. Installation des packages npm
### 1.a) Installation avec MAJ manuelle
- Dans le terminal tapez : `npm i` 

> Ou

### 1.b) Installation avec MAJ auto
 *VULNERABILITE: néccésitera une vérification avec la commande `npm audit fix`*

- Dans le terminal tapez : `npm install`


## 2. Demarrez l'api depuis le terminal 
- Démarrez une seconde fenêtre de terminal
- Acceder au dossier du projet et tapez : `expo start`

### 2.a) Lancer l'api sur l'émulateur d'un MAC

Après avoir lancer la commande expo start, [l'url](http://localhost:19002/) se lance automatiquement.
- Activer le mode local
- Cliquer sur run on IOS Emulator

### 2.b) Lancer l'api sur Smartphone
*RAPPEL: Pour lancer l'émulateur il faut avoir installé Expo!*

Scanner le QRCode depuis Expo.
